# 合成示例：电源与接口小板的分级审查

本示例的板卡、器件、网络与判据全部虚构，仅说明怎样报告，不可用作真实器件设计依据。
假定受控需求 REQ-A Rev.1：电源稳定供主控、输入状态在复位期可靠采样、两路用户接口。
原理图 SYN-A Rev.1 共 3 页，配置 A。输入清单/全量逐项结果在真实项目中必须另行提供；
本节是格式示范，未提供的 JSON 不声称已经运行。

**原理图不准出。** 已确认 P0 1 项、P1 1 项、P2 1 项；可选改善 1 项。
另有潜在 P0 待核 1 项。不能把待核的严重后果计入确认缺陷。

## 面向新手的逐项修改说明

下面补充的位号、引脚及数据同样是合成设定；实际报告须逐项回到原始证据。
结构化字段见 [remediation-guide](../references/remediation-guide.md)，不能只保留上方摘要表。

### F-01：条件满足后修改

目的：恢复核心供电。此例已确认 `U5.3→SUPPLY→R1.1；R1.2→CORE→U4.8`，
R1在本配置不贴。尚需从受控BOM/电源设计取得跳线额定和主控负载/时序，确认源能力。

1. 在p1定位R1，核1脚SUPPLY、2脚CORE；保持这两端的现有导线。
2. 当电流/时序校核允许使用原0Ω桥时，将本配置R1从DNP改为贴装，BOM数量1。
   0Ω的封装、额定电流与最大电阻取已核原厂BOM；用最大电阻算压降/功耗，不能拿理想0Ω免算。
3. 复出网表/BOM，确认当前配置已贴，源物理脚到U4.8确有路径；再测启动/峰值压降。

若源能力不足，先设计新的受控电源路径。不得在保留原桥的同时并入另一稳压输出。

### F-02：条件满足后修改

目的：保证U2.3在采样窗口保持低。当前外部下拉R2接BOOT→GND；芯片内部上拉未知。
从U2准确手册取得内部上拉、漏电和采样时序，从电源要求取得电压上下界。

1. 保持R2.1→U2.3所在BOOT网、R2.2→GND，先不盲填10kΩ。
2. 画出 `VCC→内部上拉→BOOT→R2→GND`；忽略漏电时先用
   `VBOOT=VCC×R2/(R内部+R2)`筛查，再将漏电、阻值公差及采样时电容全部代入。
3. 选出令VBOOT,max≤本例0.8V的标准阻值，同时保证对端翻转时灌/拉电流合法。
   在表中给最终值/精度/功率/封装及计算来源后，再更新R2/BOM。
4. 复核导出值，并在复位释放附近测U2.3；整段采样窗口≤0.8V且满足setup/hold才通过。

### F-03：条件满足后修改

目的：让维护软件读到FAULT。先从U3手册确认U3.4是开漏还是推挽、有效极性和耐压；
从实际pinmux表找已确认空闲且电平兼容的输入。本例没有提供这些数据，因此不编造目标GPIO。

1. 把“U3.4 FAULT→待分配输入”的逻辑通道加入外设分配表，填入真实物理脚后才能连线。
2. 若确认是开漏，增加上拉支路 `接收端合法电源→R_new→FAULT`；由VOL/IOL、漏电、
   上升时间和失电耐受决定阻值/额定。若是推挽，则按实际输出规格处理，不套开漏模板。
3. 形成确切脚号/参数后画连线并更新固件映射；新网表应连接U3.4与所选输入，
   人为触发/清除故障时测电平，软件读数与有效极性一致。

### I-01：可直接修改

在p1定位U1.2，只去掉与已有正确ENABLE连线冲突的No-connect属性。保持导线、网名和
装配不变。重新导出后对应属性告警应消失，U1.2仍在ENABLE网；前后pin→net差分无意外变化。
这是一步文档/属性修正，不需要新增电气参数或套用上电测试流程。

修改准备度只表示编辑细节是否齐全，与缺陷严重度和板卡准出独立；下游验证继续保留HANDOFF。

**结论：开放 P0/P1、未决高潜在风险及未落实下游约束关闭前，本版原理图不准出。**
