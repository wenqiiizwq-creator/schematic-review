# 原理图能力与自动化边界

2026-09-17核对。用于解释能力及防止漏查，不代替SKILL.md的完整审查流程。
“工程审查要求已覆盖”“有自动候选”和“有参数计算器”是三件事；表中缺口不能由零命中宣称通过。
修改相关脚本后应同步维护本表。范围仅限原理图，结果继续采用schema 3及三等级。

| 能力 | 已有自动实现 | 仍须Agent完成/当前缺口 |
|---|---|---|
| 电源树：输入→稳压器→电源轨→负载 | `checkers/powertree.py`回溯到输出脚或按状态声明的外部源，经过受支持的已贴装串联无源件及显式方向路径；`plan_review.py`生成部分逐轨拓扑/预算任务 | 来源查询会在找到一个源候选后返回，不是完整多级稳压器/全部负载树。逐轨ER2计划仍按轨名正则枚举，可能漏掉`+3V3`等已被来源模块识别的轨；须从全部物理供电脚、原厂资料和网表补全。逐状态负载、效率、裕量和电流预算由Agent有据计算 |
| 反馈分压推算稳压输出 | Rule-08、`solve_dividers.py`支持实际串并联电阻及受限线性网络，使用Vref/电阻公差/偏置保证值计算窗口 | 先核固定/可调、真实反馈端点及全部负载支路；缺保证输入保持INSUFFICIENT。设定值不等于可达输出，dropout、启动和稳定性另查 |
| 子电路识别及连接 | 注册表识别I²C、去耦、感性负载、功率开关、输入滤波、上电、监控、差分、光耦；另有FB/EN/strap/接口候选 | 尚非通用全电路分解器；运放、晶振、ADC、通用RC/LC等完整清单须人工补充。`intent.circuits`按已声明电路展开判据，不证明自动发现了全部电路；逐物理脚追踪及图面核对仍必做 |
| 每个外部连接器的ESD覆盖 | Rule-10检查已识别ESD/TVS脚是否挂在单节点残网；通用清单要求每个对外连接器逐针考虑防护 | 尚无通用“连接器每针→网络→保护件→被保护脚/返回网”的自动覆盖清单。无ESD器件时Rule-10可零命中，不能判防护充分。Agent逐针列明外露/接口要求、保护件或NA依据、方向/泄放、VRWM/VC/电容等条件；需求缺失保持待核。PCB摆放和真实抗扰度仅交接 |
| 无源网络验证 | 分压、并联上拉等效阻值、公差窗口、去耦连接/标称容量清单，以及输入滤波一阶阻尼等专项工具 | Rule-09通过只证明其声明的连接/等效阻值范围，不自动证明I²C电平和上升时间。尚无通用RC/LC拓扑识别→截止/谐振/阻尼/负载效应→逐网络结论的完整流水线。晶振负载、RC时序、R功耗、C有效值/耐压、L峰值/饱和等按公式、原厂规格和真实工况逐项完成 |

准确用语：具备这些领域的原理图工程审查要求和部分自动工具；不宣称全部同等自动化。
后续原理图自动化优先补完整电源树/负载枚举、逐连接器ESD覆盖、通用无源网络识别与计算。
