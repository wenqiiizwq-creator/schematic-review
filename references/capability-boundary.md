# 原理图能力与自动化边界

2026-09-17核对。用于解释能力及防止漏查，不代替SKILL.md的完整审查流程。
“工程审查要求已覆盖”“有自动候选”和“有参数计算器”是三件事；表中缺口不能由零命中宣称通过。
修改相关脚本后应同步维护本表。范围仅限原理图，结果继续采用schema 3及三等级。

| 能力 | 已有自动实现 | 仍须Agent完成/当前缺口 |
|---|---|---|
| 电源树：输入→稳压器→电源轨→负载 | `checkers/powertree.py`回溯到输出脚或按状态声明的外部源，经过受支持的已贴装串联无源件及显式方向路径；`plan_review.py`生成部分逐轨拓扑/预算任务 | 来源查询会在找到一个源候选后返回，不是完整多级稳压器/全部负载树。逐轨ER2计划仍按轨名正则枚举，可能漏掉`+3V3`等已被来源模块识别的轨；须从全部物理供电脚、原厂资料和网表补全。逐状态负载、效率、裕量和电流预算由Agent有据计算 |
| 反馈分压推算稳压输出 | Rule-08、`solve_dividers.py`支持实际串并联电阻及受限线性网络，使用Vref/电阻公差/偏置保证值计算窗口 | 先核固定/可调、真实反馈端点及全部负载支路；缺保证输入保持INSUFFICIENT。设定值不等于可达输出，dropout、启动和稳定性另查 |
| 子电路识别及连接 | 原有9类注册检查器之外新增逐针ESD与RC/LC候选归组、未归属无源件清单；另有FB/EN/strap/接口候选 | 尚非通用全电路分解器；运放、晶振、ADC和非标准器件继续补查。`intent.circuits`不证明已自动发现全部电路；逐物理脚追踪及图面核对仍必做 |
| 每个外部连接器的ESD覆盖 | `connector_esd`/ES-01从连接器物理脚出发，列网络、逐通道保护/返回映射、受限串联路径、可达端点、装配与豁免依据；无保护器件也逐针生成缺口；Rule-10继续查残网 | 自动发现不保证非标准端口全量，须核BOM/图面及官方完整脚表。映射是拓扑候选；Agent核暴露/需求、VRWM/适用VC、双向摆幅、注入、返回及信号负载。缺通道/状态/需求保持待核，不自动判ESD合格；真实抗扰度交接 |
| 无源网络验证 | `passive_networks`/PN-01归组RC/LC并对账剩余R/C/L；PN-10验证实际支路、源/负载、有效值和资料绑定，算常见RC/LC闭式指标及一般RLC指定频点的增益区间；逐网络计划含模型、AC与额定/时域审查 | 常见闭式指标有明确拓扑/ESR条件；一般RLC限12未知节点/24元件/256频点，超限、区间过宽、非线性/耦合/未知保证值保持INSUFFICIENT。任意高阶全频带、开关/晶振/采样瞬态、R功耗、C耐压、L饱和等仍需适用模型与工程验算 |
