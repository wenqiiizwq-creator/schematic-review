# 原理图审查通用检查表（按电路域）

本表是待实例化的检查方向，不是全部器件通用的数值规范。按项目器件/接口/需求裁定适用性；每条必须独立记录
PASS / FAIL / INSUFFICIENT / NA、证据和证据置信度。只能由网表、原理图、BOM、
需求和 datasheet 定判的内容进入 PASS/FAIL；布局、实测或结构事项另记独立
HANDOFF，可与本项审查结果并存。

## 1. 电源输入与保护
- [ ] 输入保险丝/PTC 额定与降额（项目适用降额规范逐项核对）
- [ ] 输入 TVS：核 VRWM/VBR/VC 各自定义；按实际浪涌波形、电流与温度将钳位窗口对后级绝限，缺工况不定判
- [ ] 防反接电路（MOSFET 理想二极管/二极管）方向与栅极钳位
- [ ] 热插拔：UVLO/OVLO 窗口与母线匹配；限流点 vs 系统需求；浪涌 I=C·dV/dt vs 源端限制；输入电容总量 vs 平台限制（如 ≤500µF）
- [ ] 连接器单针额定与并针电流（原理图判定）；PCB 走线载流另记 HANDOFF

## 2. DCDC / LDO（每颗必过）
- [ ] FB 分压代入实际阻值复算输出电压（电阻公差、VFB 保证范围、偏置与温度；E96 不证明精度），与目标轨和负载器件推荐工作条件（min/typ/max）比对
- [ ] Vref 基准值以 datasheet 为准（不写印象值）
- [ ] EN：有效极性 vs 上/下拉；EN 耐压 vs 所接轨（先读 Abs Max）
- [ ] 软启动/浪涌；min on-time 核算（高频+大降压比时）
- [ ] 电感 Isat/DCR、输出电容总量与 ESR、补偿网络电气接法
- [ ] 去耦/储能电容的位置、回路和大电流铜皮要求另记 HANDOFF
- [ ] 自印降额规范（如 DCDC 80%）执行核对

## 3. 电压监控 / 复位芯片
- [ ] 器件档位从订货表/丝印确认（固定阈值版本 vs 可调；−5%/−10% 档）
- [ ] 每路动作点复算：VTHx = Vth_pin × (R1+R2)/R2；**下臂串联电阻求和**；给 typ + min/max 范围
- [ ] 被监测轨确认（同名不同域的轨分清）
- [ ] 动作点 vs 页面注释意图、vs 被保护器件的工作下限（报警太晚=监测失效）
- [ ] 输出链：开漏上拉、上拉电源域、串联/滤波、到主控的终点

## 4. 时钟
- [ ] 晶振 CL 与外接电容匹配（等效 CL = C1×C2/(C1+C2) + Cstray；按晶振料号 CL 核算，不看"典型印象值"）
- [ ] 反馈电阻、串联电阻按 datasheet/参考设计
- [ ] RTC 晶振 32.768kHz（丝印笔误高频）；外部 RTC 备份电池/超级电容充电电压 < 上限
- [ ] 有源振荡器使能脚/电平域

## 5. 复位与启动配置
- [ ] 按门限/电源爬升/快速再上电计算 RC 复位有效脉宽；复位链每一跳连通
- [ ] 启动模式/BOOT 脚默认电平有确定驱动（上电采样窗口不悬空）
- [ ] strap 采样电平：节点上 LED/其他上拉对采样窗口分压的影响
- [ ] Recovery/Maskrom 等救砖通道存在

## 6. 主控 / SoC
- [ ] 全部电源球有驱动（Rule-05）、全部 VSS 球入地（Rule-06）
- [ ] 各 IO 电源域实际电压 vs 相连外设电平
- [ ] 去耦电容与参考设计一致性
- [ ] 未用 PHY/外设电源脚处置按平台规范（悬空/接地/关闭）
- [ ] 调试口（UART/JTAG/SWD）可达、串阻、ESD

## 7. 存储
- [ ] eMMC/SD：IO 电平、CMD 上拉、CLK/STROBE 串阻、测试节点是否电气预留
- [ ] 高速测试点是否允许、stub 禁止条件与布局要求另记 HANDOFF
- [ ] DDR：按具体代际/MPN 核 ZQ 阻值/精度/终接轨、VREF/VTT/ODT 与各电源域，禁止套用统一 ZQ 接法
- [ ] SPI Flash：VCC 域、上拉、写保护

## 8. 接口（逐路核对双向连通 + 方向语义）
- [ ] USB：REXT、DP/DM 串阻、VBUS 检测、ID、ESD 在活线上
- [ ] UART/RS232/RS485：TX/RX 方向回官方引脚表复述；端接、偏置、防护
- [ ] CAN：收发器供电/VIO、STBY/EN 默认态、120Ω 端接策略（本端/对端书面明确）、隔离方案
- [ ] I2C：逐电气段合并板内/外部上拉及公差，按 IOL/VOL、tr/Cb 求可行阻值窗口；另核电平、地址、串阻压降和掉电状态
- [ ] SPI：CS/时钟极性、串阻
- [ ] 以太网：MDI 差分对 P/N、变压器 CT 端接、Bob Smith 75R+1nF/2kV、MDIO 上拉、PHY 复位与 strap
- [ ] RF/模组：天线路径默认通断、供电电容阵总量 vs 规格书最小值、开关机/复位驱动 vs 参考设计、SIM 卡 ESD 与上拉
- [ ] 阻抗、等长、间距、回流、过孔、连接器前后保护器件摆放顺序提取为 HANDOFF

## 9. 电平域与电平转换
- [ ] 跨电压接口（1.8V↔3.3V 等）有转换器或书面确认两端同域
- [ ] 上拉轨须同时满足所有接收端门限、耐压、掉电容忍及转换器要求；不能固定取较高或较低域
- [ ] 网络命名与电平一致（DBG_*_3V3 实为 1.8V 属误导）

## 10. 防护链（逐段点名）
- [ ] 雷击/浪涌（GDT/TSS）→ ESD → 端接 → 隔离，段间配合（动作电压、能量）
- [ ] ESD 器件挂在活线上（Rule-10）
- [ ] 跨隔离带器件/网络归属与跨接电容耐压；实际爬电距离另记 HANDOFF
- [ ] 对外连接器每针防护考虑

## 11. 无源器件
- [ ] 每颗受应力电阻核功耗、连续/脉冲工作电压与温度；降额取项目规则，缺规则标假设
- [ ] 电容耐压降额（自印规范，如 50%）；MLCC 直流偏压有效容量
- [ ] 分压/采样/ZQ 精度由允许误差窗口与器件要求决定，不能默认 1% 即合格
- [ ] 电解电容寿命核算（高温满载场景换固态）

## 12. 连接器
- [ ] pinout 与对端定义逐针核对（板内自洽 ≠ 对端正确）
- [ ] 按连接器实际并针降额、接触电阻/均流、线缆与故障电流核载流，不能直接按单针额定乘针数放行
- [ ] 防误插、pin1 标识
- [ ] 未用针处置（悬空 vs 接地，平台规则）

## 13. 原理图电气损耗与热约束
- [ ] 可由原理图确定的电阻、开关器件和稳压器损耗/额定值
- [ ] 温度传感器电气连接、量程和接口正确
- [ ] PCB 热路径、铜皮、风道和实际结温统一另记 HANDOFF，不在本检查定判

## 14. 测试节点与器件数据
- [ ] 关键 rail、strap 点、调试信号是否需要并已电气预留测试节点
- [ ] TP 可触达性、邻近地、夹具与 ICT 覆盖另记 HANDOFF
- [ ] BOM 值字段无异常字符串（4.7F 类笔误）
- [ ] 库卫生：符号名 = 实物 MPN（防采购误读）

## 15. 文档与图纸卫生
- [ ] 页面注释与实贴 BOM 一致（注释=意图，BOM=现实，都核）
- [ ] 遗留命名/注释清理（换方案残留）
- [ ] 网络命名规范、无双胞胎名
- [ ] 图框信息、版本一致性（PDF vs 网表导出时间）
- [ ] 需求/规格书与原理图参数口径统一（电流/电压数字唯一来源）

## 16. 模拟/监测与工况
- [ ] ADC 量程、供电、每脚绝限、共模/差分、采样建立时间、误差预算分别核
- [ ] 运放输入共模/输出摆幅、带宽/压摆率/稳定性、未用通道接法按具体料号
- [ ] 监测量/取样侧/返回地/判决/控制/反馈完整，检查循环启动
- [ ] 开关的连续电流、限流值、快断时间、热保护和 SOA 分别核，不能互代
- [ ] 需求内启动、掉电、外部带电、热插拔、故障与恢复状态，以及每种装配配置

## 平台条款实例化

每个官方条目记录：文档/版本/页码、适用器件和模式、条款强制性、预期连接/窗口、
实际位号/物理脚/网络、检查 ID、结果和 HANDOFF。参数不从另一项目复制。
ZQ 终接、eMMC 电压、晶振串并阻、USB 检测和网口端接均按准确型号/代际/平台版本核实。

## 16. 保护、模拟及新接口的独立检查

- [ ] 热插拔/电子保险丝：MOS 在限流阶段的 VDS-I-t SOA、热态降额、故障计时、重试能量与熔断器协调；不能只算 I²Rds(on)
- [ ] DCDC：峰值/RMS 电流、Isat、最小 on/off 时间、最坏限流；LDO：dropout、反向电流、耗散、Cout/ESR 与稳定性
- [ ] 运放：共模/输出摆幅、失调/偏置误差、GBW/压摆率和容性负载；ADC：采样建立、源阻抗、基准驱动、注入电流和掉电保护
- [ ] USB Type-C/PD：Source/Sink/DRP、CC/Rp/Rd、VBUS 供电条件/档位、放电、反灌、过流和 VCONN
- [ ] CAN/RS485：按真实端点/支路和外部设备核对端接、空闲偏置、接收保证门限、共模及未供电负载
- [ ] 时钟：CL 以外还需准确料号的 ESR/驱动等级、振荡器适配和上电有效时间；寄生和起振裕量另作 HANDOFF
