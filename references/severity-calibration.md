# 三等级分级与证据校准

新报告的严重程度只使用小写error、warning、suggestion；不用编号、字母、图标、颜色
或“潜在级别”形成另一套等级。技术结果、证据充分性、处理状态和是否影响冻结独立记录。

| 等级 | 判断依据 | 处理方式 |
|---|---|---|
| error | 连接与适用官方保证值/受控需求已证实过压、主要功能连接错误、必需功能缺项或工作范围违规 | 修改并复验；未修复不能准出 |
| warning | 有具体电气风险机制、局部非关键应用偏离，或关键工况尚未证实满足要求 | 按影响计算、测试或修改，写出触发工况与缺证 |
| suggestion | 物料二义、库字段/封装文字与Value对应不清、图框身份、一般资料补齐、后续阶段交接或可选改进；尚无实际电气错误证据 | 给整理/确认方法和完成条件，不自动认定电路失效 |

## 逐项判断与边界

每项记录事实、适用判据、影响对象/功能、触发工况、独立保护、后果证据及归类理由。
不能按规则号、缺文件数量或手册的must一词自动定级，也不编造概率/RPN。

- PART与Value冲突但真实物理脚和电路映射已核一致：suggestion。建立身份分支，取得受控BOM、
  封装回读证据；不得擅自把某字段认定为实际物料。
- 官方物理脚证明符号把电源与地对应反了，或实际焊盘连接确实错位：按电气后果列error/warning，
  写明端点；不能用“封装问题”把已证实电气错误降为建议。
- 仅缺时钟完整料号、Flash手册、对端ICD、PCB资料：通常suggestion。若现有线路已显示
  过压、冲突或反灌机制，把该独立风险列warning/error，并关联资料项。
- 非关键指示灯驱动不足、NC脚局部应用偏离可为warning；主要功能、保证范围违规可为error。
- 输入低于器件保证下限、必需启动偏置不满足保证值：error。无需等样机必然失败，
  但“不保证”不能写为“每次失败”；室温一次成功不证明全温/批次满足。
- 高压PG超过同网耐压：error。区分未钳位设定电压、注入电流与实测节点电压。
- 参数窗口很窄但缺纹波/温漂/负载条件：warning。缺资料不等于严重故障；已有风险
  也不能因缺实测就归普通资料建议。
- DDR映射已核正确，剩余控制器约束、SI/PI、PCB落实：suggestion并保留交接；
  不提出无原厂依据的DDR改线，不把后续阶段未执行认定为原理图错误。

## 技术事实与计数

机器保留review_result=PASS/FAIL/INSUFFICIENT/NA、A/B/C证据描述及关闭状态，均不是等级。
PASS/FAIL只能基于直接证据或有依据的推导；关键证据不足保持INSUFFICIENT。
正文用“已核实的偏离”“风险尚需验证”“资料待补齐”等中文说明，不并列等级徽标。

DEFECT表示确认偏离（也可为suggestion级文档问题），RISK表示尚未确认的整体结论，
IMPROVEMENT表示已满足已知要求后的可选改进。缺资料不能伪装为IMPROVEMENT。
同根因只计一个ID，多检查链接不重复计数。总数统计全部唯一ID的三等级；
另列确认偏离、风险与改善数量，不能把待核风险混称为已证实电气错误。

## 冻结判断与历史迁移

error必须修复后复验。warning/suggestion是否影响冻结由明确需求、工况、输入完整性和
交接边界决定，逐条填写blocking及blocking_reason。普通物料/文档整理不自动阻断，
关键输入不足和必需交接也不能因等级降低而消失。后续阶段测试留待后续执行；
本阶段需要交接的约束、接收角色和方法应落实。

只调整等级时，保留原技术结果、证据、缺失条件、详细改法、验收、关闭状态和阻断处置；
确需改阻断另给依据或责任方记录，不能自动改false。不自行接受风险，
接受记录不把FAIL/INSUFFICIENT改为PASS。修复须新版证据，撤回须反证，字段变了不等于修好。

脚本仍兼容旧schema_version=2，只作历史复核。新台账用schema_version=3。
迁移逐ID重评并保存旧→新理由，没有固定一对一映射；不把旧等级写回新报告/CSV。
