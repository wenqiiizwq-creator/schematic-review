# 让硬件新手能执行的修改说明

在写任何发现的修改建议前读本页。目标是让读者能根据原理图定位并完成指定编辑，
知道哪些参数已有依据、哪些仍要确定，以及用什么结果验收。指导编辑不等于授权代改设计。
真实位号/物理脚来自当前版本；新器件用“建议新增，位号待分配”，不能伪称已有空闲位号。

## 修改准备度

| readiness | 报告中文 | 适用条件 |
|---|---|---|
| READY | 可直接修改 | 本项原理图编辑所需连接、规格和前提已齐；无未决选型/输入 |
| CONDITIONAL | 条件满足后修改 | 拓扑方案已明确，参数或受控装配/资料前提未齐；给取得及判断方法 |
| DESIGN_REQUIRED | 需要重新设计 | 架构、模式、控制脚或接口方案未确定；先列设计步骤和选择依据 |

准备度与 P0–P3 严重度、证据置信度、缺陷关闭状态彼此独立。READY 不表示可以直接上电、
修改已验证或整板准出。候选参数不能用于承诺“照填即完成”；不得用 CONDITION/DESIGN
标签逃避现有资料可完成的计算、连接核对和具体操作。

## 每项应说清的内容

1. **定位和目的**：PDF实际页/页名、位号.物理脚、网络；用一句普通话解释应恢复的行为。
   例如说明“上拉电阻使控制脚在主控尚未接管时保持高电平”，再说明该高电平对应开还是关。
2. **前后状态**：给旧→新值/装配/网络；需要换源时先写断开哪条旧连接，再写新路径。
   路径以 `源物理脚 → 网 → 已贴器件.脚 → 网 → 接收物理脚` 表达；含串阻时列两段网。
   仅加同名标签可能使所有同名端合并，须列受影响成员；不能用一条新导线旁路串阻/开关。
3. **顺序操作**：定位→断旧/改件→连新→更新BOM/装配→检查。简单问题只需实际必要步骤，
   不为凑数量拆句。不猜EDA菜单，不给用户当前未用工具的点击教程。需图形才能解释的
   分压、多级开关、二极管方向、复杂控制链给小图/连接表，并标清器件脚号。
4. **规格与依据**：被动件给值/精度及相关功率、耐压、封装、贴装；保护/有源件给所需范围、
   后缀/封装与物理脚定义，精确MPN须有原厂依据。只列该改动真正需要的参数。
   给公式、实际输入、公差/温度边界、结果与验收窗。未知项说明取得处和选择方法；
   如“取得最大输入电压后按 P=V²/R 计算，再按器件温度降额曲线选额定”，不能只写“重算”。
5. **联动及验收**：指出需要一起解决的ID以及改后受影响状态。每条验证写方法、测点/工况、
   预期连通/范围/现象。区分编辑后的网表/计算验收与PCB、固件、实物验证；不把待做测试写成已通过。

不要仅给“接到合适GPIO”“加ESD”“参考典型应用”“复算环路”“加10k上拉”这样的终点句。
应继续给已知连接/模式/指标、待选变量、查找章节/计算步骤和通过条件。如果没取得某颗IC的
实际封装脚表，就写清缺口；不能为了具体而编造脚号。选项较多时给推荐方案及选择条件，
让新手知道从哪条路径开始，而非把所有可能器件列给读者自行设计。

## 三种修改类型的尺度

### 连接/装配已有唯一依据

合成例：p2，R10为已确认的10kΩ上拉，U2.4为3.3V输入。受控BOM要求R10贴装，
当前 `R10.1→3V3；R10.2→U2.4` 已接对但装配状态为DNP（不贴）。

- 将R10的装配选项从DNP改成贴装，并使导出BOM的该位号数量恢复为1；阻值保持10kΩ。
- 本例规定1%/0402/额定≥0.063W，最坏3.465V及−1%阻值时功耗约1.22mW；依据合成要求SYN-R1，
  实际项目须用自己的温度降额依据。无需改这两端的已有导线。
- 导出新网表/BOM：R10被解析为当前配置已贴，两端分别在3V3和U2.4所在网；不是只检查名字删除了NC。

### 方向明确但参数未定

例：输出泄放。先画清 `VOUT → R_new → GND` 的并联支路，不能串入主供电路径。
从受控要求取得 `Vmax、最大输出电容Cmax、目标残压Vsafe、允许时间tmax、温度`；
计算 `R≤tmax/[Cmax·ln(Vmax/Vsafe)]`，再核连续 `Pmax=Vmax²/Rmin`、阻值公差及功率降额。
有外部负载/主动泄放时用实际模型。只有条件算例时明确标“候选，不能据此定版”，
并写读者取得哪些输入后可把候选改为已选。

### 需要重新设计

例：默认关断链。先列输入电源与控制电源存在/不存在、主控复位/高阻/运行时的目标输出；
核EN极性与门限、内部默认拉阻、掉电耐受。对已掌握芯片给实际脚号；对未选器件用功能端名。
推荐能覆盖状态表的拓扑，标出源/控制/输出端及与已有电路的接入点；再给电平/电流不等式、
器件工作条件及选型方法。主控脚尚未分配时必须取得pinmux表，不能臆造“空闲GPIO”。
列出状态覆盖与参数确定后才能做的编辑及验收，不能以“找专业人员处理”代替设计说明。

上述数字和位号均为合成示例，不是通用推荐值。真实项目不得复用未核实的参数。

## 结构化字段与机器检查

保持最终结果 `schema_version: 2`，新增顶层 `remediation_version: 1`。每个 finding 加：

```json
{
  "remediation": {
    "readiness": "READY",
    "purpose": "使主控复位期间输入保持规定的高电平。",
    "prerequisites": [],
    "steps": [{
      "kind": "ASSEMBLY",
      "target": "PDF p2 R10",
      "before": "DNP，不贴装",
      "after": "贴装，BOM数量1；阻值10kΩ保持",
      "instruction": "在当前配置中启用R10贴装，并同步BOM装配选项。"
    }],
    "parameters": [{
      "target": "R10",
      "specification": "10kΩ，1%，0402，额定≥0.063W，贴装",
      "status": "SELECTED",
      "basis": [{"source": "synthetic-requirements.md", "locator": "SYN-R1 and power calculation"}]
    }],
    "related_findings": [],
    "impact_review": "核3V3存在而主控复位的默认态；输出灌电流按已列规格核算。",
    "verification": [{
      "stage": "NETLIST",
      "method": "导出本配置网表和BOM，逐端检查R10。",
      "expected": "R10已贴；R10.1在3V3，R10.2与U2.4同网。"
    }]
  }
}
```

- `steps`按数组顺序执行，至少一项。`kind`为CONNECT / COMPONENT / ASSEMBLY /
  DOCUMENT / DESIGN；每步均有非空target/before/after/instruction。
- CONNECT额外提供 `remove_connections` 和 `add_connections` 数组，每条为
  `{"from":"R1.2","to":"U1.3"}`，至少一侧非空；缺哪端必须先列前提。
  端点可以是物理脚或明确的命名网络，不能把连线序列写成短接所有节点。
- `parameters`为数组，文档/纯连线修改可为空。每条target/specification/status/basis
  均必须有内容；status为SELECTED / CANDIDATE / TBD，后两者还须needed_input和selection_method。
  COMPONENT/ASSEMBLY步骤至少有一条规格记录，贴装、固定或待定都必须明确。
- `prerequisites`为数组；每项含input/reason/how_to_obtain/acceptance。READY必须为空，
  也不能含候选/待定参数或DESIGN步骤；其他准备度至少给一项真实未决前提。
- `related_findings`是同报告其他finding ID数组，可空，不可指向自身/不存在ID。
  `impact_review`非空；没有电气影响的文档改动说明应保留哪些连接/字段。
- `verification`至少一项stage/method/expected；stage为NETLIST / CALCULATION /
  DOCUMENT / BENCH / PCB。必须包含至少一项前三类的编辑/计算验收，不能只有未来上电观察。

新报告必须执行 `validate_review.py ... --require-actionable`。旧v2台账不加此选项仍可做
兼容校验；带remediation_version的台账会自动校验新字段。校验器只能检查结构和准备度
矛盾，不能证明操作语义、计算或新手理解程度。交付前仍需按这些步骤对照真实输入逐项演算。
