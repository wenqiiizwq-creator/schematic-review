# 参数、工作范围与修改建议验算

先列模型、拓扑、实际贴装值、单位、来源、适用输入/负载/温度和边界；再算 min/typ/max。
公差、温漂、线/负载调整率、基准误差不能只留 typ，也不能把已包含的误差重复相加。
缺输入写条件计算与 INSUFFICIENT，脚本默认 1% 或 Vref 零公差不是原厂保证。

## 常用判据

| 对象 | 计算与核对 | 常见误判防线 |
|---|---|---|
| 可调 FB | Vset=Vref×(1+Rtop/Rbottom)，按上下臂反向公差求区间；脚本处理明确串并联 | 先核固定档/内置电阻/反馈注入；完整路径中共享电阻、支路负载、分压脚偏置电流须节点分析 |
| LDO | Vin(min)−Vout(max)≥所需负载/温度的 dropout(max)，核反向电流、Cin/Cout/ESR | 公式算 7.25V 而 Vin 仅 5.4V 表示设定不可达/可能失调，不代表器件能输出 7.25V；还须核真实 MPN |
| Buck | D≈Vout/Vin，ton≈D/fsw；再按器件损耗模型、最小导通/关断、工作模式验算 | 改 RT 后同时核最大 VIN 的 ton、L 纹波/Isat/Irms、Cout/ESR、补偿及损耗 |
| 供电窗口 | 将电源含全角窗口与每个负载推荐工作范围相交；绝限另查 | 未超 Abs Max 不能当作工作正常；轨名只是标称意图 |
| UVLO/OVLO/监控 | 按具体门限结构公式，分别给 rising/falling、内部迟滞电流、精度与电阻公差 | 固定档不用可调 Vref；启动门限与维持门限分开；取样侧由测量目标决定 |
| 限流/断路 | Itrip(min)=Vth(min)/Rs(max)，max 反向；分别算快断、恒流、功率限制、TIMER | 最大连续电流额定值不等于电流触发阈值；软件检测不自动满足硬件保护要求 |
| 电流/功率预算 | 各状态下负载峰值、效率、同时工作系数和上游能力；Ipeak≈Iout+ΔIL/2 | 裕量依据需求/策略；Isat 与温升电流分别核，不能只比平均值 |
| 热插拔/软启 | 电容充电 I=Ceff×dV/dt 加启动负载，核上游快断、eFuse/MOS SOA、重试占空比 | 输出大电容及外接设备也计入；启动 SOA 不由稳态 I²R 替代 |
| 电阻/泄放 | P=V²/R、I²R，电阻工作电压；放电 t=RC ln(Vstart/Vsafe) | 改 24V 泄放电阻同时算满压常态功耗和温度降额；不得仅按放电速度给封装 |
| RC 复位 | 一阶阶跃充电 t=−RC ln(1−Vthreshold/Vfinal)，放电另算 | τ=RC 不是保证脉宽；电源爬升、阈值、钳位、内部上拉、快速再上电须计入 |
| 逻辑/strap | VOH(min)≥VIH(min)，VOL(max)≤VIL(max)，核采样时刻电压窗口与上升时间 | LED/多上拉/内部拉/漏电/三态同时作用；不定区是“不保证”，按需求影响分级 |
| I²C | Rp(eq)=1/Σ(1/Ri)；Rp(min)=(Vpullup−VOL(max))/IOL；Rp(max)=tr(max)/(0.8473Cb) | 按最弱器件、总线模式及上下拉公差求界；多组上拉可合法，不固定要求只留一组或 1–4.7kΩ |
| 跨域/掉电 | 分别核接收端门限、允许输入/注入电流、Ioff、VDD=0 条件、转换器供电顺序 | 不固定接“较高域”或“较低域”；没有直接兼容窗口时用合适转换器/隔离器 |
| ADC/运放 | 分压输出窗口、每脚绝对电压、共模、差分 FSR、输入阻抗/采样建立、参考误差；运放输入共模/输出摆幅/稳定性 | FSR 不等于引脚耐压；rail-to-rail 不是任何负载/频率下都贴电源轨 |
| TVS/Zener | VRWM、VBR、VC@指定 Ipp/波形、容差/温度、源阻抗/能量及后级绝限配合 | 不能把 VRWM/Vz 当最大钳位，也不能拿额定测试电流的 VC 当任意工况实际峰值；低流拐点/回路寄生另核 |
| 无源/晶振 | 电压/电流/功耗/精度/温度；CL=C1C2/(C1+C2)+Cstray，核 ESR、驱动与起振条件 | MLCC Ceff 用具体 MPN 偏压/温度/容差曲线，不套 40–70%；Cstray 不固定用 3–5pF |

纯电阻分压可运行 `python3 scripts/solve_dividers.py db.json --vfb U1=0.8 --vfb-tol 0.02`。
这是显式假设示例；Vref/精度需换成当前器件有出处的值。多源、共享电阻、截断或未知阻值
不能返回确定解。内部反馈或有负载的网络需用受控模型另算，记录脚本不支持范围。

## 修改建议的第二次审查

对每项建议写“旧值/旧网→新值/新网”、假设、修改后全角计算、关联器件、装配状态和通过标准。
未掌握输入/负载/保护窗口时不给唯一确定阻值或替代料。禁止用“软件强制某模式”替代硬件保护，
除非需求允许且启动/掉电/故障场景均有依据；不能自动豁免明确必需的功能。
只由 PCB/实测决定的寄生、真实温升、SI/EMC 列 HANDOFF，仍完成原理图可算的应力与损耗。

## 原厂出处（2026-09-07 核对）

- [NXP UM10204 Rev.7.0 §7.1，p.50–51](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)：
  I²C 上拉上下界、上升时间与总线电容的关系。使用具体器件 IOL/VOL 及接口模式。
- [TI ADS111x SBAS444E §7.3.3，p.15，Table 7-1](https://www.ti.com/lit/ds/symlink/ads1115.pdf)：
  FSR 是转换量程设置，模拟脚电压仍受供电与绝限约束；不能把 ±4.096V 当成 3.3V 供电时的脚耐压。
